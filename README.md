# مُقلة | Muqla

لوحة مراقبة إجهاد العين (React + Vite). النسخة الحالية **محاكاة** لمعدل الرمش والإجهاد، وليست كشفاً حقيقياً من الكاميرا.

## التشغيل
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

## ملاحظة
لدمج كشف حقيقي للرمش، يمكن استخدام MediaPipe Face Landmarker ومعالجة الفيديو داخل المتصفح.
